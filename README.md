
Retail Sales Analysis using Python and Power BI
# Superstore Retail Analytics

## Project Overview
This project focuses on analyzing retail sales data to understand business performance, customer behavior, product sales, and profitability.

The main objective is to identify useful business insights through Python data analysis and interactive Power BI dashboards.

## Project Objectives
- Analyze overall sales and profit performance.
- Identify top-performing product categories and regions.
- Understand customer purchasing behavior.
- Analyze the impact of discounts on profitability.
- Create interactive dashboards for business decision-making.

## Tools & Technologies
- **Python** – Data analysis
- **Pandas** – Data cleaning and manipulation
- **Jupyter Notebook** – Exploratory Data Analysis (EDA)
- **Power BI** – Interactive dashboard development
- **SQL** – Data analysis and querying
- **Microsoft Excel** – Data handling

## Dataset
The project uses the Sample Superstore dataset, which contains retail information such as:
- Order Date
- Customer Details
- Product Category
- Sales
- Profit
- Discount
- Region
- Quantity
